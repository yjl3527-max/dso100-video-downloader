# DSO100 视频下载扩展

这是一个基于 Chrome Manifest V3 的短视频下载扩展，支持抖音、小红书、快手和懂车帝等平台。

## 当前版本

`1.2.4`

## 主要能力

- 单个下载任务串行排队，连续点击不会互相覆盖。
- 批量下载支持选择内容、进度反馈和失败项重试。
- 小红书卡片下载会把解析和下载统一放入队列。
- 后台下载使用浏览器默认下载目录，减少重复保存操作。
- 下载状态面板显示进度、失败数量、取消和重试操作。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。

部分解析功能需要在扩展内登录 DSO100 账号，并受平台页面状态和第三方解析接口影响。
